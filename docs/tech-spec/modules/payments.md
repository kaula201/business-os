# მოდული: Payments (გადახდები)

**კოდი:** `payments`
**Route:** `/payments`
**კატეგორია:** operations
**დამოკიდებულია:** `invoices`
**გვერდი:** `frontend/src/pages/PaymentsPage.tsx` (135 სტრიქონი)
**Backend:** `payments.py`

---

## მიზანი

გადახდის კარიბჭის მართვა: გადახდების სია, შექმნა, დადასტურება, დაბრუნება (refund).

## გვერდის სტრუქტურა

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „ახალი გადახდა" | ღილაკი | შექმნის ფორმა |
| „შექმნა" | ღილაკი | გადახდის შექმნა (`paymentsApi.create`) |
| გადახდის რიგი | ცხრილი | ინვოისი, თანხა, მეთოდი, სტატუსი |

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/payments/` | `list_payments` | სია |
| POST | `/payments/` | `create_payment` | შექმნა |
| POST | `/payments/{payment_id}/confirm` | `confirm_payment` | დადასტურება |
| POST | `/payments/{payment_id}/refund` | `refund_payment` | დაბრუნება |

## ბიზნეს ლოგიკა

- გადახდა უკავშირდება ინვოისს
- **დადასტურება:** ამცირებს დავალიანებას და ქმნის GL გატარებას
- **Refund:** გადახდის დაბრუნება (საპირისპირო გატარება)
