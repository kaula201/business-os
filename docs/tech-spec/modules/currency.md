# მოდული: Currency (ვალუტის კურსები)

**კოდი:** `currency`
**Route:** `/currency`
**კატეგორია:** finance
**გვერდი:** `frontend/src/pages/CurrencyPage.tsx` (318 სტრიქონი)
**Backend:** `currency.py`

---

## მიზანი

ვალუტის კურსების მართვა: ხელით დამატება, ეროვნული ბანკიდან (NBG) ავტომატური სინქრონიზაცია, კონვერტაცია.

## გვერდის სტრუქტურა

### 1. კურსების სია

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „კურსის დამატება" | ღილაკი | ხელით კურსის შეყვანა |
| „გადართვა" | ღილაკი | ძირითადი ვალუტის გადართვა |
| „გადაყვანა" | ღილაკი | კონვერტაციის კალკულატორი |
| „ყველა ვალუტა" / „მხოლოდ არჩეული" | ღილაკები | ფილტრი |
| „ახლდება..." | ღილაკი | NBG-დან სინქრონიზაცია |

### 2. NBG სინქრონიზაცია

- `GET /currency/rates/nbg-status` — ბოლო სინქრონიზაციის სტატუსი
- `POST /currency/rates/sync-nbg?rate_date=...` — კურსების ჩამოტვირთვა NBG-დან

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/currency/rates` | `list_rates` | კურსების სია |
| POST | `/currency/rates` | `create_rate` | ხელით დამატება |
| DELETE | `/currency/rates/{rate_id}` | `delete_rate` | წაშლა |
| POST | `/currency/rates/sync-nbg` | `sync_nbg_rates` | NBG-დან სინქრონიზაცია |
| GET | `/currency/rates/nbg-status` | `nbg_sync_status` | სინქრონიზაციის სტატუსი |
| POST | `/currency/convert` | `convert_currency` | კონვერტაცია |

## ბიზნეს ლოგიკა

- **NBG ინტეგრაცია:** კურსები იღება ეროვნული ბანკის API-დან (`nbg_rates.py` სერვისი)
- **კონვერტაცია:** `convert_currency` ითვლის თანხას არჩეული კურსით
- კურსები გამოიყენება ბუღალტერიაში საკურსო სხვაობებისთვის
