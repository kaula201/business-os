# მოდული: Assets (ძირითადი საშუალებები)

**კოდი:** `assets`
**Route:** `/assets`
**კატეგორია:** finance
**გვერდი:** `frontend/src/pages/AssetsPage.tsx` (507 სტრიქონი)
**Backend:** `assets.py`

---

## მიზანი

ძირითადი საშუალებების აღრიცხვა: აქტივები, ამორტიზაციის გრაფიკი, ამორტიზაციის გატარება, ჩამოწერა (dispose).

## გვერდის სტრუქტურა

### 1. აქტივების სია

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „აქტივის დამატება" | ღილაკი | შექმნის ფორმა |
| აქტივის რიგი | ცხრილი | სახელი, საწყისი ღირებულება, ნარჩენი, სტატუსი |

### 2. აქტივის დეტალები

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „ირიცხება..." | ღილაკი | ამორტიზაციის გატარება (`run-depreciation`) |
| ამორტიზაციის ისტორია | ცხრილი | `GET /assets/{id}/depreciation-history` |
| ამორტიზაციის გრაფიკი | ცხრილი | `GET /assets/{id}/schedule` |
| „მუშავდება..." | ღილაკი | ჩამოწერა (`dispose`) |

### 3. მასობრივი ოპერაციები

- „იქმნება..." — ყველა აქტივის ამორტიზაცია (`POST /assets/run-all-depreciation`)

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/assets/` | `list_assets` | სია |
| GET | `/assets/{asset_id}` | `get_asset` | ერთი აქტივი |
| POST | `/assets/` | `create_asset` | შექმნა |
| PUT | `/assets/{asset_id}` | `update_asset` | განახლება |
| DELETE | `/assets/{asset_id}` | `delete_asset` | წაშლა |
| POST | `/assets/{asset_id}/run-depreciation` | `run_depreciation` | ამორტიზაცია |
| GET | `/assets/{asset_id}/depreciation-history` | `depreciation_history` | ისტორია |
| GET | `/assets/{asset_id}/schedule` | `depreciation_schedule` | გრაფიკი |
| POST | `/assets/run-all-depreciation` | `run_all_depreciation` | ყველას ამორტიზაცია |
| POST | `/assets/{asset_id}/dispose` | `dispose_asset` | ჩამოწერა |

## ბიზნეს ლოგიკა

- **ამორტიზაცია:** ხაზოვანი მეთოდი, გრაფიკი ითვლება აქტივის ვადის მიხედვით
- **გატარება:** ამორტიზაცია ქმნის GL ჩანაწერს (ხარჯი ↔ დაგროვილი ამორტიზაცია)
- **ჩამოწერა:** აქტივის ნარჩენი ღირებულების ჩამოწერა
