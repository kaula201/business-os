# მოდული: BankBatch (ბანკის პარტიული დამუშავება)

**კოდი:** `bank-batch`
**Route:** `/banking` (ნაწილი)
**კატეგორია:** finance
**დამოკიდებულია:** `banking`
**გვერდი:** არ არის ცალკე გვერდი (banking-ის ნაწილი)
**Backend:** `bank_batch.py`

---

## მიზანი

ბანკის შეჯერების წინადადებების პარტიული დამტკიცება — ერთი მოქმედებით მრავალი შეჯერების წინადადების დამტკიცება.

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| POST | `/bank-reconciliations/batch-approve` | `batch_approve_suggestions` | წინადადებების პარტიული დამტკიცება |

## ბიზნეს ლოგიკა

- ირჩევს ყველა დაუმუშავებელ შეჯერების წინადადებას და ამტკიცებს ერთდროულად
- გამოიყენება მაშინ, როცა წინადადებები სანდოა (მაგ. წესებით გენერირებული)
