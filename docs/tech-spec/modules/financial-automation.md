# მოდული: FinancialAutomation (ფინანსური ავტომატიზაცია)

**კოდი:** `financial-automation`
**Route:** `/gl/automation`
**კატეგორია:** accounting
**დამოკიდებულია:** `gl`
**გვერდი:** არ არის ცალკე გვერდი (გამოიყენება პერიოდის დახურვისას)
**Backend:** `financial_automation.py`

---

## მიზანი

ფინანსური ავტომატიზაციის ერთიანი გაშვება — პერიოდის დახურვისას ყველა ავტომატური ოპერაცია ერთი ღილაკით: ამორტიზაცია, გადავადებული აღიარებები, განმეორებადი ჩანაწერები, საკურსო სხვაობები.

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| POST | `/gl/automation/run` | `run_automation` | ყველა ავტომატური ოპერაციის გაშვება |

## ბიზნეს ლოგიკა

- ერთი გაშვება ასრულებს: ამორტიზაციას, გადავადებულ აღიარებებს, განმეორებად ჩანაწერებს, საკურსო სხვაობებს
- გამოიყენება პერიოდის დახურვის წინ (AccountingPeriods გვერდიდან)
