# მოდული: LiveChat (ცოცხალი ჩატი)

**კოდი:** `live-chat`
**Route:** `/live-chat`
**კატეგორია:** operations
**გვერდი:** არ არის ცალკე გვერდი (ჩატი ქვედა მარჯვენა კუთხეში)
**Backend:** `live_chat.py`

---

## მიზანი

შიდა ცოცხალი ჩატი — მომხმარებლებს შორის მიმოწერა სისტემაში (AI ასისტენტის ჩატის გვერდით).

## სტრუქტურა

- ჩატის ფანჯარა ქვედა მარჯვენა კუთხეში
- შეტყობინებების სია, გაგზავნა, წაშლა

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/live-chat/` | `list_messages` | შეტყობინებების სია |
| GET | `/live-chat/{message_id}` | `get_message` | ერთი შეტყობინება |
| POST | `/live-chat/` | `create_message` | გაგზავნა |
| DELETE | `/live-chat/{message_id}` | `delete_message` | წაშლა |

## ბიზნეს ლოგიკა

- შეტყობინებები ინახება ბაზაში (კომპანიის ფარგლებში)
- გამოიყენება შიდა კომუნიკაციისთვის
