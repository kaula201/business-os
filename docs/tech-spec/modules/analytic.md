## მიზანი

ანალიტიკური აღრიცხვა — ხარჯების/შემოსავლების დაყოფა ანალიტიკურ ცენტრებზე (პროექტი, დეპარტამენტი, პროდუქტი) და განაწილების წესები.

## გვერდის სტრუქტურა

### 1. ანალიტიკური ცენტრები

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „ცენტრი" | ღილაკი | ახალი ცენტრი |
| „შენახვა" | ღილაკი | ცენტრის შენახვა |

### 2. ანალიტიკური ჩანაწერები

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „ჩანაწერი" | ღილაკი | ახალი ჩანაწერი |
| „შენახვა" | ღილაკი | ჩანაწერის შენახვა |
| „გაუქმება" | ღილაკი | ფორმის დახურვა |

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/analytic/accounts` | `list_accounts` | ცენტრები |
| POST | `/analytic/accounts` | `create_account` | ცენტრის შექმნა |
| PUT | `/analytic/accounts/{account_id}` | `update_account` | განახლება |
| GET | `/analytic/entries` | `list_entries` | ჩანაწერები |
| POST | `/analytic/entries` | `create_entry` | ჩანაწერის შექმნა |
| DELETE | `/analytic/entries/{entry_id}` | `delete_entry` | წაშლა |
| GET | `/analytic/allocation-rules` | `list_allocation_rules` | განაწილების წესები |
| POST | `/analytic/allocation-rules` | `create_allocation_rule` | წესის შექმნა |
| GET | `/analytic/gl-reconciliation` | `gl_reconciliation` | GL-თან შეჯერება |

## ბიზნეს ლოგიკა

- ანალიტიკური ჩანაწერი უკავშირდება GL ჩანაწერს და ცენტრს
- განაწილების წესები ავტომატურად ანაწილებს ხარჯებს ცენტრებზე (პროცენტულად)
- `gl_reconciliation` ამოწმებს, რომ ყველა GL ჩანაწერი დაფარულია ანალიტიკით
