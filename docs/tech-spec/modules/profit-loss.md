## მიზანი

მოგება-ზარალის ანგარიში (P&L) — შემოსავლები, ხარჯები და წმინდა მოგება პერიოდის მიხედვით.

## გვერდის სტრუქტურა

- შემოსავლების სექცია (გაყიდვები, სხვა შემოსავლები)
- ხარჯების სექცია (COGS, საოპერაციო ხარჯები)
- წმინდა მოგება/ზარალი
- პერიოდის ფილტრი

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/gl/profit-loss/` | `profit_loss` | P&L ანგარიში |

## ბიზნეს ლოგიკა

- **შემოსავალი:** ინვოისის დადასტურებისას (შემოსავლის ანგარიშზე კრედიტი)
- **COGS:** მომწოდებლის ინვოისის დამტკიცებისას (ხარჯის ანგარიშზე დებეტი)
- **ხარჯები:** ხარჯების მოდულიდან, ამორტიზაციიდან, სახელფასოდან
- **წმინდა მოგება = შემოსავლები − ხარჯები**
