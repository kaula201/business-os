# მოდული: Notifications (შეტყობინებები)

**კოდი:** `notifications`
**Route:** `/notifications`
**კატეგორია:** operations
**გვერდი:** არ არის ცალკე გვერდი (ზარი ზედა ზოლში)
**Backend:** `notifications.py`

---

## მიზანი

სისტემური შეტყობინებები: წაუკითხავი შეტყობინებების დათვლა, სია, წაკითხულად მონიშვნა.

## სტრუქტურა

- ზარის ხატულა ზედა ზოლში — წაუკითხავი რაოდენობა
- შეტყობინებების ჩამოსაშლელი სია
- „ყველას წაკითხულად მონიშვნა"

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/notifications/` | `list_notifications` | შეტყობინებების სია |
| GET | `/notifications/unread-count` | `unread_count` | წაუკითხავი რაოდენობა |
| POST | `/notifications/{notification_id}/read` | `mark_read` | ერთის წაკითხულად მონიშვნა |
| POST | `/notifications/read-all` | `mark_all_read` | ყველას წაკითხულად მონიშვნა |

## ბიზნეს ლოგიკა

- შეტყობინებები იქმნება ავტომატურად: დავალების მინიჭება, დამტკიცების მოთხოვნა, ვადის მოახლოება
- `unread_count` იძახება პერიოდულად (ზარის ხატულაზე ბეჯი)
