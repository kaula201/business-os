## მიზანი

განმეორებადი საჟურნალო ჩანაწერების შაბლონები — ავტომატურად იქმნება ჩანაწერი ყოველ პერიოდში (ქირა, ხელფასი, აბონემენტი).

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/gl/recurring/` | `list_recurring` | შაბლონები |
