## მიზანი

ბანკის ტრანზაქციების ავტომატური შეჯერების წესების მართვა — წესი ადარებს ტრანზაქციის აღწერას და ავტომატურად უკავშირებს შესაბამის ანგარიშს/კონტრაგენტს.

## გვერდის სტრუქტურა

### 1. წესების სია

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „ახალი წესი" | ღილაკი | შექმნის ფორმა |
| „წესების გამოყენება" | ღილაკი | ყველა წესის გაშვება (`apply_all_rules`) |
| „შენახვა" | ღილაკი | წესის შენახვა |

### 2. წესის ფორმა

| ველი | ტიპი | შენიშვნა |
|------|------|----------|
| სახელი | input | |
| პირობა (აღწერა შეიცავს...) | input | მატჩის ტექსტი |
| სამიზნე ანგარიში | select | GL ანგარიში |
| კონტრაგენტი | select | კლიენტი/მომწოდებელი |

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/banking/reconciliation-rules/` | `list_rules` | წესების სია |
| POST | `/banking/reconciliation-rules/` | `create_rule` | შექმნა |
| PATCH | `/banking/reconciliation-rules/{id}` | `update_rule` | განახლება |
| DELETE | `/banking/reconciliation-rules/{id}` | `delete_rule` | წაშლა |
| POST | `/banking/reconciliation-rules/apply` | `apply_all_rules` | ყველა წესის გამოყენება |
