## მიზანი

სამზარეულოს ეკრანი (KDS — Kitchen Display System): რესტორნის შეკვეთები ჩნდება სამზარეულოში, მზარეული აღნიშნავს მზადების სტატუსს.

## გვერდის სტრუქტურა

### 1. შეკვეთების რიგი

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| შეკვეთის ბარათი | ბარათი | მაგიდა, პოზიციები, დრო |
| „მზადება" | ღილაკი | სტატუსი → cooking (`PATCH /pos/orders/{id}/kitchen-status`) |
| „მზადაა" | ღილაკი | სტატუსი → ready |

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/pos/kitchen/queue` | `kitchen_queue` | სამზარეულოს რიგი |
| PATCH | `/pos/orders/{order_id}/kitchen-status` | `set_kitchen_status` | სტატუსის ცვლილება |

## ბიზნეს ლოგიკა

- შეკვეთა ჩნდება სამზარეულოში POS-იდან გაგზავნისას
- სტატუსები: pending → cooking → ready
- „მზადაა" სტატუსი აცნობებს მიმტანს, რომ კერძი მზადაა გასატანად
