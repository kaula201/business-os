# მოდული: ExchangeDifferences (საკურსო სხვაობები)

**კოდი:** `exchange-differences`
**Route:** `/gl-exchange-differences`
**კატეგორია:** accounting
**დამოკიდებულია:** `gl`, `currency`
**გვერდი:** `frontend/src/pages/ExchangeDifferencesPage.tsx` (97 სტრიქონი)
**Backend:** `exchange_differences.py`

---

## მიზანი

საკურსო სხვაობების გადაფასება — უცხოურ ვალუტაში არსებული ნაშთების გადაფასება მიმდინარე კურსით და სხვაობის GL-ში გატარება.

## გვერდის სტრუქტურა

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „გადაფასება" | ღილაკი | გადაფასების გაშვება (`POST /gl/exchange-differences/run`) |
| სხვაობების სია | ცხრილი | ანგარიში, ვალუტა, ძველი/ახალი კურსი, სხვაობა |

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| POST | `/gl/exchange-differences/run` | `run_exchange_differences` | გადაფასება |
| GET | `/gl/exchange-differences/` | `list_exchange_differences` | სხვაობების სია |

## ბიზნეს ლოგიკა

- გადაფასდება ყველა უცხოური ვალუტის ანგარიში (მოვალეები, ვალდებულებები, ბანკი)
- სხვაობა ირიცხება საკურსო სხვაობების ანგარიშზე (შემოსავალი/ხარჯი)
- კურსი იღება ვალუტის მოდულიდან
