## მიზანი

საცდელი ბალანსის ანგარიში — ყველა ანგარიშის დებეტი/კრედიტი ნაშთები პერიოდის მიხედვით. ამოწმებს ბუღალტრული ჩანაწერების სისწორეს (დებეტი = კრედიტი).

## გვერდის სტრუქტურა

- ანგარიშის რიგები: კოდი, სახელი, დებეტი, კრედიტი, ნაშთი
- პერიოდის ფილტრი (თარიღიდან/თარიღამდე)
- ექსპორტი: `GET /gl/export/trial-balance`
