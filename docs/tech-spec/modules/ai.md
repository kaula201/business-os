# მოდული: AI (AI ასისტენტი)

**კოდი:** `ai`
**Route:** `/ai`
**კატეგორია:** other
**გვერდი:** `frontend/src/pages/AIPage.tsx` (169 სტრიქონი)

---

## მიზანი

AI ასისტენტი — ჩატი კომპანიის მონაცემებზე (RAG): მომხმარებელი სვამს კითხვას ბუნებრივ ენაზე, სისტემა პასუხობს ბაზაში არსებული მონაცემების საფუძველზე.

## გვერდის სტრუქტურა

### 1. ჩატის ინტერფეისი

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| შეტყობინებების სია | ჩატი | მომხმარებლის + AI-ს შეტყობინებები |
| შეყვანის ველი | textarea | კითხვის დაწერა |
| გაგზავნა | ღილაკი | `POST /ai/chat` |

### 2. სწრაფი მოქმედებები

- `GET /ai/quick-actions` — წინასწარ განსაზღვრული კითხვები (მაგ. „რამდენია დღევანდელი შემოსავალი?")

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| POST | `/ai/chat` | `chat` | კითხვა-პასუხი RAG-ით |
| GET | `/ai/quick-actions` | `get_quick_actions` | სწრაფი მოქმედებები |
| POST | `/ai/reindex` | `reindex_data` | მონაცემების ხელახალი ინდექსაცია |

## ბიზნეს ლოგიკა

- **RAG:** მონაცემები ინდექსირდება pgvector-ში (`embedding.py`, `rag.py` სერვისები)
- **ინდექსაცია:** კლიენტები, შეკვეთები, ინვოისები, დავალებები — ვექტორული ძებნა
- **reindex:** მონაცემების ცვლილებისას ხელახალი ინდექსაცია
- **უსაფრთხოება:** პასუხები შემოიფარგლება მიმდინარე კომპანიის მონაცემებით (RLS)
