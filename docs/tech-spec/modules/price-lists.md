# მოდული: PriceLists (ფასების სიები)

**კოდი:** `price-lists`
**Route:** `/price-lists`
**კატეგორია:** sales
**დამოკიდებულია:** `products`
**გვერდი:** `frontend/src/pages/PriceListsPage.tsx` (190 სტრიქონი)
**Backend:** `price_lists.py`

---

## მიზანი

ფასების სიების და გადახდის პირობების (payment terms) მართვა — სხვადასხვა კლიენტისთვის/სეგმენტისთვის სხვადასხვა ფასები.

## გვერდის სტრუქტურა

### 1. ტაბები

| ტაბი | ფუნქცია |
|------|----------|
| „ფასების სიები" | ფასების სიების მართვა |
| „გადახდის პირობები" | გადახდის პირობების მართვა |

### 2. ფასების სიები

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „ახალი ფასების სია" | ღილაკი | შექმნის ფორმა |
| „სტრიქონის დამატება" | ღილაკი | პროდუქტის + ფასის დამატება |
| „შენახვა" | ღილაკი | სიის შენახვა |

### 3. გადახდის პირობები

- სახელი, დღეების რაოდენობა, ფასდაკლება

## API Endpoints

### ფასების სიები

| მეთოდი | Path | ფუნქცია |
|--------|------|---------|
| GET | `/price-lists/` | `list_price_lists` |
| POST | `/price-lists/` | `create_price_list` |
| PATCH | `/price-lists/{price_list_id}` | `update_price_list` |
| DELETE | `/price-lists/{price_list_id}` | `delete_price_list` |

### გადახდის პირობები

| მეთოდი | Path | ფუნქცია |

| PATCH | `/payment-terms/{term_id}` | `update_payment_term` |
| DELETE | `/payment-terms/{term_id}` | `delete_payment_term` |

## ბიზნეს ლოგიკა

- ფასების სია შეიცავს პროდუქტებს თავისი ფასებით — გამოიყენება შეკვეთებში/ინვოისებში
- გადახდის პირობები განსაზღვრავს ვადებს (მაგ. 30 დღე) და ფასდაკლებას ადრეულ გადახდაზე
