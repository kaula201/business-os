## მიზანი

ელ.ფოსტის გაგზავნა და კალენდრის მოვლენების მართვა.

## გვერდის სტრუქტურა

### 1. ელ.ფოსტა

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „ახალი ელ.ფოსტა" | ღილაკი | წერის ფორმა |
| „გაგზავნა" | ღილაკი | გაგზავნა (`POST /email-calendar/emails`) |

### 2. კალენდარი

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „შექმნა" | ღილაკი | მოვლენის შექმნა (`POST /email-calendar/events`) |
| მოვლენების სია | ცხრილი | სათაური, თარიღი, მონაწილეები |

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/email-calendar/emails` | `list_emails` | ელ.ფოსტების სია |
| POST | `/email-calendar/emails` | `send_email` | გაგზავნა |
| GET | `/email-calendar/events` | `list_events` | მოვლენები |
| POST | `/email-calendar/events` | `create_event` | მოვლენის შექმნა |
| DELETE | `/email-calendar/events/{event_id}` | `delete_event` | წაშლა |

## ბიზნეს ლოგიკა

- ელ.ფოსტა იგზავნება SMTP-ით (ან sandbox-ში ინახება `email_messages`-ში)
- კალენდრის მოვლენა შეიძლება უკავშირდებოდეს დავალებას
