## მიზანი

გადავადებული შემოსავლების/ხარჯების აღიარება — თანხა იყოფა პერიოდებზე და აღიარდება ეტაპობრივად (მაგ. წლიური გამოწერა).

## გვერდის სტრუქტურა

### 1. გრაფიკები

| ელემენტი | ტიპი | ფუნქცია |
|----------|------|----------|
| „ახალი გრაფიკი" | ღილაკი | შექმნის ფორმა |
| გრაფიკის რიგი | ცხრილი | ანგარიში, თანხა, პერიოდები, სტატუსი |
| „აღიარება" | ღილაკი | ერთი პერიოდის აღიარება (`recognize_one`) |
| „მუშავდება..." | ღილაკი | ყველა ვადამდებელი აღიარება (`recognize_due`) |
| „იქმნება..." | ღილაკი | გრაფიკის შექმნა |

### 2. ფორმა

| ველი | ტიპი | წყარო |

## API Endpoints

| მეთოდი | Path | ფუნქცია | აღწერა |
|--------|------|---------|--------|
| GET | `/deferred/schedules` | `list_schedules` | გრაფიკები |
| POST | `/deferred/schedules` | `create_schedule` | შექმნა |
| POST | `/deferred/recognitions/{id}/recognize` | `recognize_one` | ერთი აღიარება |
| POST | `/deferred/recognize-due` | `recognize_due` | ყველა ვადამდებელი |
| POST | `/deferred/preview-due` | `preview_due` | პრევიუ |
| POST | `/deferred/recognitions/{id}/reverse` | `reverse_recognition` | აღიარების გაუქმება |
| POST | `/deferred/schedules/{id}/cancel` | `cancel_schedule` | გრაფიკის გაუქმება |

## ბიზნეს ლოგიკა

- გრაფიკი ყოფს თანხას თანაბარ ნაწილებად პერიოდებზე
- აღიარება ქმნის GL ჩანაწერს (გადავადებული ანგარიშიდან → შემოსავალზე/ხარჯზე)
- `recognize_due` აღიარებს ყველა ვადამდებელ ნაწილს ერთდროულად
